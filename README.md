## 📖 Progulaについて

**Progula（プログラ）**は、スキマ時間を利用して本格的なプログラミングを学べる、インタラクティブなWEB学習プラットフォームです。

「プログラミング学習を始めたいけれど長続きしない」「どこから手を付ければいいかわからない」という方の悩みを解決するために開発されました。  
初心者でも迷わず進められる短いステップ形式のレッスンと、ゲーム感覚で楽しめる継続の仕組みを提供しています。

---

## ✨ 主な特徴

### 💻 多彩なプログラミング言語コース
Pythonをはじめ、JavaScriptやTypeScriptなど、現代のWeb開発やデータ分析で広く使われている主要な言語カリキュラムを展開しています。

### ⚡ 実践的なインタラクティブ学習
1レッスン数分の短いステップで構成されているため、通勤・通学時間や休み時間などの「スキマ時間」に着実に進められます。

### 🎮 モチベーションを維持するゲーム機能
- **🔥 連続学習記録（ストリーク）:** 毎日の学習を記録し、学習習慣の定着をサポートします。
- **⚡ XP（経験値）システム:** レッスンをクリアするごとにXPを獲得し、レベルアップ
- **❤️ ライフシステム:** 緊張感をもってチャレンジできるライフ機能を搭載。
