## 🌟 概要

**Progula（プログラ）**は、スキマ時間で本格的なプログラミングを学べるインタラクティブな学習プラットフォームです
Python、JavaScript、TypeScriptなど多彩な言語コースを用意しており、コードを書いて動かす実践的なレッスンを通じて、初心者から着実にスキルを習得できます

毎日の学習を楽しく続けるための「連続学習記録（ストリーク）」やXP（経験値）システムも充実しており、モチベーションを維持しながら無理なくプログラミングの習慣化が目指せます💡

🔗 **公式サイト:** [https://progula.ai.studio/](https://progula.ai.studio/)

---

## ✨ 主な機能

- 🐍 **多彩な言語コース:** Pythonなどのカリキュラムを用意し、基礎からステップアップ。
- ⚡ **実践的なレッスン:** 4問のステップやコード記述を通じて、手を動かしながら楽しく学習。
- 🔥 **連続学習記録（ストリーク）:** 毎日の学習をカレンダーで可視화し、継続するモチベーションをアップ。
- ❤️ **ライフ & XPシステム:** ゲーミフィケーション要素を取り入れ、楽しくゲーム感覚でスキルアップ。
