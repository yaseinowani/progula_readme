## 📖 Progulaについて

**Progula（プログラ）**は、スキマ時間を利用して本格的なプログラミングを学べる、インタラクティブなWeb学習プラットフォームです[cite: 1]。

WebフロントエンドからAI・データ分析、低レイヤやエンタープライズ開発まで、幅広い領域をカバーする**全10言語のコース**を用意[cite: 1]。初心者でも迷わず進められるステップ形式のレッスンと、ゲーム感覚で楽しめる継続の仕組み（ストリークやXPシステム）で、無理なくプログラミングの習慣化が目指せます💡[cite: 1]

---

## ✨ 主な特徴

### 💻 充実の10言語カリキュラム
初心者向けのHTML/CSSやPythonから、上級者向けのC++やC言語まで幅広い言語をラインナップ[cite: 1]。自分の学習目的に合わせて自由にコースを選択・変更できます。

### ⚡ 実践的なハンズオン学習
知識のインプットだけでなく、ブラウザ上で実際にコードを書いて動かす実践的なレッスンを採用[cite: 1]。1レッスン数分の短時間で完結するため、通勤・通学時間などの「スキマ時間」に着実にスキルを習得できます[cite: 1]。

### 🎮 モチベーションを維持するゲーム機能
- **🔥 連続学習記録（ストリーク）:** 毎日の学習を記録し、モチベーションを維持しながら習慣化をサポート[cite: 1]。
- **⚡ XP（経験値）システム:** レッスンをクリアするごとにXPを獲得してレベルアップ！[cite: 1]
- **❤️ ライフシステム:** ゲーム感覚で適度な緊張感をもってチャレンジできます[cite: 1]。
